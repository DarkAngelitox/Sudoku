# SUDOMI CORE 0.1 🇩🇴

Primera base independiente del proyecto. Conserva las versiones antiguas fuera de este proyecto.

## Objetivo de esta versión
Motor Sudoku + tablero + notas + resaltado + errores + pistas + timer + pausa + undo/redo + victoria/derrota + guardado local.

## Importante
Esta versión es un **checkpoint de prueba**, no la versión final. La dificultad avanzada y las técnicas del solver se seguirán endureciendo antes de marcar el Core como aprobado.

## Probar
Abrir `index.html`. Para GitHub Pages, subir el contenido de esta carpeta conservando las rutas.
