# SUDOMI 0.2.4 — Home navigation refinement

Based on SUDOMI 0.2.3.

- Added a left-side dropdown menu for Entrenamiento, Modo Profesor, Logros, Perfil, Personalizar, and Configuración.
- Each dropdown option opens the existing “Función en desarrollo” notice.
- Enlarged and spaced the main home options: Sudoku del día, Multijugador, and Estadísticas.
- The menu closes when a feature is selected, when the user clicks outside it, or when Escape is pressed.
- Preserves the resume/new-game flow from 0.2.3.

This is a static web app. Upload the contents of this folder to the repository to publish it as a versioned GitHub Pages folder.
