# SUDOMI 0.2.0 — Home screen

Based on the approved local Sudomi Core 0.1.7 build. This version adds the planned home screen and keeps the existing Sudoku game available through **Jugar**.

- Shows all ten planned menu options from the beginning.
- Opens a development notice for unfinished sections.
- Pauses the active game when returning home and resumes it through **Jugar**.
- Keeps the timer paused on the home screen, including at initial load.
- Leaves the previous `sudomi-core-0.1.7` folder unchanged.

The other menu sections are presentation placeholders; their full features are planned for later phases.
