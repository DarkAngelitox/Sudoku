# Sudomi Core 0.1.7

Based on the local `sudomi-core-0.1.6.1` folder. This version changes only the Sudoku board layout and matching-number color:

- Defines nine equal rows and nine equal columns with zero-minimum tracks, so blank rows keep their height.
- Highlights matching numbers in blue, including numbers in given cells. Wrong entries retain their red styling.

All game logic and other styling are carried forward unchanged.
