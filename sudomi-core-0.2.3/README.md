# SUDOMI 0.2.3 — Resume or start new

Based on SUDOMI 0.2.2.

- Returning home silently pauses and saves the current unfinished game; it hides the in-game pause overlay.
- Pressing **Jugar** with an unfinished game opens a choice to resume or start a new game.
- **Reanudar partida** returns directly to the saved board and resumes the timer without showing the pause overlay.
- **Nueva partida** opens the six-level difficulty picker.
- If there is no unfinished saved game, **Jugar** opens the difficulty picker directly.
- Legacy saved games are treated as resumable when valid and unfinished.

No browser/device tests have been run for this version.
